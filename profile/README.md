# 47Geese

**Useful software. Open to everyone.**

47Geese starts with real problems, builds practical software to address them, and releases it as open source. Use it as it is, run it yourself, or make it your own with AI.

🌐 **[47geese.com](https://47geese.com)**

## Projects

| Project | What it is | Status |
| --- | --- | --- |
| **Quire** | Open-source curriculum mapping and visualization. Explore relationships across curricula, understand how things connect, and make complex information easier to navigate. | In development |
| **Nylon** | Open-source chat for open-source healthcare projects: channels, threads and projects that link to their code. Shows DOIs, PubMed IDs, GitHub repos and FHIR pages as cards, and checks for patient details before anything is posted. | In development |

## Use it. Adapt it. Make it yours.

- **Use** – run the software as provided, on your own infrastructure.
- **Adapt** – change it yourself, or point an AI coding agent at it and make it fit what you need.
- **Learn** – explore the code, the architecture and the decisions behind it.

## Why 47Geese exists

Building is easier. Solving problems is harder. AI has commoditized software; the harder part is understanding a problem well enough to solve it. That's where we focus our efforts:

1. Understand the problem
2. Explore possibilities
3. Experiment and learn
4. Share what works
